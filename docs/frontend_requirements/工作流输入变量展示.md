# 工作流「输入变量」展示优化（前端需求）

> 组件：`src/components/rpa-browser/WorkflowEditDialog.vue` → 输入变量区
> 纯逻辑：`src/utils/workflowVarFields.ts`（已抽离并单测）
> 变量定义来源：被引用动作的 `input_vars`（声明）+ `input_variables`（模板反射），工作流只存值

## 1. 现状问题

1. 值与说明挤在一行（`w-52` 名称列 + `w-60` 输入框），长值（URL / key / system_prompt）看不全；
2. **长文本**（如 `llm_system_prompt`，几百字含换行）被渲染成单行 `el-input`，无法阅读与编辑；
3. 类型直接显示 schema 原词（`string` / `array`），对使用者不友好；
4. 错误只有底部一条全局提示，不知道是哪个变量错了；
5. `api_key` 类变量**明文**显示；
6. `array` / `object` 只有「保存时」才校验 JSON，编辑中无反馈，也没有「格式化」；
7. 没有「恢复默认值」入口，改坏了只能手动还原。

## 2. 目标布局（每个变量一张卡片）

```
┌───────────────────────────────────────────────────────────────┐
│ llm_fallbacks  [数组] *            [格式化 JSON]  [恢复默认]   │  ← 头部
│ 备用模型池（JSON 数组，主模型失败时按顺序回退）…               │  ← 描述（2 行截断 + 悬浮全量）
│ ┌───────────────────────────────────────────────────────────┐ │
│ │  （值控件：全宽；JSON 用等宽多行文本域）                    │ │
│ └───────────────────────────────────────────────────────────┘ │
│ 不是合法 JSON                                                  │  ← 字段级错误（仅该字段）
└───────────────────────────────────────────────────────────────┘
```

- 卡片：`action-vars-item`，`flex flex-col gap-2 p-3 bg-fill-light rounded border`；
- 头部：名称（等宽 `font-mono`）+ 类型标签 + 必填星号，右侧操作按钮（`text` 按钮，仅在可用时显示）；
- 描述：`text-xs text-text-secondary`，`line-clamp-2` + `title` 悬浮看全；
- 控件：**全宽**，不再固定 `w-60`；
- 错误：紧跟控件下方，`text-xs text-danger`。

## 3. 控件选择规则

| 条件 | 控件 | 说明 |
| --- | --- | --- |
| `type === 'boolean'` | `el-select`（是/否） | 宽度 `w-40`，右侧留白 |
| `type === 'array'` 且声明了 `items_schema` | **结构化数组编辑器**（`ObjectArrayEditor.vue`） | 按元素结构逐字段填写，无需手写 JSON；见 §3.1 |
| `type === 'array' \| 'object'` 且无 `items_schema` | `el-input type="textarea"`，`rows=4`，等宽字体 | JSON 文本；失焦校验，支持「格式化 JSON」 |
| `type === 'string'` 且（默认值含换行 或 长度 > 60） | `el-input type="textarea"`，`rows=3` | 如 `llm_system_prompt` |
| 名称匹配 `/(api_?key|secret|token|password|passwd|credential)/i` | `el-input type="password"` + `show-password` | 默认掩码，可点眼睛临时查看 |
| 其它 | `el-input type="text"` | 单行 |

类型标签文案：`string→文本`、`number/integer→数字`、`boolean→布尔`、`array→数组`、`object→对象`。
### 3.1 数组变量的结构化编辑（`items_schema`）

后端在动作的 `input_vars` 声明里可以带 `items_schema`（自包含 JSON Schema，无 `$ref`）：

```json
{
  "name": "llm_fallbacks",
  "type": "array",
  "default": [],
  "items_schema": {
    "type": "object",
    "properties": {
      "model":      { "type": "string", "maxLength": 200 },
      "server_url": { "type": "string", "maxLength": 2048, "format": "uri" },
      "api_key":    { "type": "string", "maxLength": 500 }
    },
    "required": ["model", "server_url", "api_key"]
  }
}
```

前端行为：

- 有 `items_schema` → 渲染与动作参数**同一套**结构化编辑器（行内增删、上移/下移、字段级校验、
  敏感字段掩码、超长省略），用户不再手写 JSON；
- 无 `items_schema` → 退回 JSON 文本域（并保留「格式化」「失焦校验」）；
- 编辑器的值在内存中仍是对象数组，写回 `inputVarValues` 时序列化成格式化 JSON 文本，
  保证保存链路不变（`parseVarInputText` 解析回数组）；
- `items_schema` 与后端模型的一致性由单测守护
  （`test/actions/test_lottery_action_selectors.py::test_fallbacks_items_schema_matches_backend_model`），
  模型改了要重新生成该字段，否则用例失败。



## 4. 状态表现

| 状态 | 表现 |
| --- | --- |
| 未填（非必填） | 空控件 + 占位符提示（`默认：xxx` 或 `请输入`），不留红字 |
| 未填（必填） | 控件正常，下方红字 `必填变量未填写`；保存按钮禁用 |
| 已填 | 正常显示；`恢复默认` 可用（仅当契约有 `default`） |
| JSON 非法 | 输入框下 `不是合法 JSON`（数组还会提示 `需要 JSON 数组`）；保存禁用 |
| 数字/布尔非法 | `需要数字` / `需要 true / false` |
| 敏感值 | 默认 `••••`；点击眼睛显形，失焦后恢复掩码 |
| 超长 | 文本域内滚动，不撑高卡片；单行输入横向滚动 + `title` 全量 |
| 契约加载中 | 区域显示「正在加载变量契约…」，不渲染卡片（也不允许保存，见 §6） |
| 无变量 | 空态文案：当前引用动作没有声明或使用任何输入变量 |

### 4.1 变量较多时的检索与汇总

- 变量数 **> 6** 时，区块头部右侧显示搜索框（`workflow-vars-section__search`）：
  按「变量名 / 描述」关键字过滤，`clearable`；过滤只影响展示，**保存仍提交全部字段**；
- 过滤后无结果 → 显示 `没有匹配的输入变量`（不显示成"当前动作没有输入变量"）；
- 底部汇总不再是第一条错误的原文（与字段级红字重复），改为计数：
  `共 N 个输入变量未通过校验（红色提示已标注在对应字段下方）`。

## 5. 交互细节

| 操作 | 行为 |
| --- | --- |
| 失焦校验 | 只有失焦后才显示该字段错误，输入过程不打断 |
| 格式化 JSON | 解析成功 → 写回 2 空格缩进文本；失败 → 显示字段级错误，不改动原文 |
| 恢复默认 | 把值设回契约 `default` 的文本形式（JSON 类型走格式化），无 `default` 时不显示该按钮 |
| 清空 | 允许把非必填项清空（保存时该键不下发，使用动作默认值） |
| 保存阻断 | 任一字段校验失败 → `canSave=false` |
| 契约未加载 | 保存时**不下发任何变量字段**（避免清空已保存值），且加载中禁用保存 |
| 仅显示已修改 | 变量数 > 3 时提供开关；勾选后只显示与打开时快照不同的变量（保存不受过滤影响） |
| 撤销修改 | 单个变量被改动后，卡片头部出现「撤销修改」，恢复为打开时的值 |
| 保存语义 | **更新**提交 `variables_patch`（只含差异键，值为 `null` 表示删除）；**新建**提交 `variables`（全量）。见 `docs/工作流变量增量更新计划书.md` |

## 6. 样式与响应式

- 卡片间距 `gap-3`；头部 `flex flex-wrap items-center justify-between gap-2`；
- 名称 `font-mono text-xs`，超长省略 + `title`；
- 类型标签用 `el-tag`（`effect=plain type=info`）；
- 必填星号 `text-danger`；
- 操作按钮 `text` 样式、无边框；「恢复默认」用次要色，不抢主操作；
- `< 640px`：头部换行、按钮换行、控件全宽；`≥ 1024px`：头部单行，控件全宽；
- 不使用 `<style>` / 内联 `:style` / `size="small"`，颜色只用主题 token。
