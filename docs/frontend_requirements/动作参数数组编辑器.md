# 动作参数「对象数组」编辑器规格（前端需求）

> 适用组件：`src/components/rpa-browser/ObjectArrayEditor.vue`（通用对象数组编辑器）
> 使用方：`ActionParamsForm.vue`（动作参数）、`WorkflowEditDialog.vue`（工作流输入变量，声明了 `items_schema` 的数组）
> 关联后端：`app/models/execution/action_param_models.py`（`params` 模型 → `params_schema`）
> 首个使用方：LLM 动作的 `fallbacks`（备用模型池），见 `docs/LLM模型回退计划书.md`

---

## 1. 范围与术语

| 术语 | 含义 |
| --- | --- |
| **列表（array）** | 参数 schema 中 `type: "array"` 且 `items` 解析后为「对象」的字段 |
| **元素（item）** | 列表中的一项，对应一个 `params` 里的对象 |
| **子字段（field）** | 元素内部的属性，由 `items.properties` 定义 |
| **列表字段（key）** | 列表本身在 `params` 中的键名（如 `fallbacks`） |

不在本规格内：基础类型数组（`items.type` 为 `string`/`number`/`boolean`，仍走 JSON 文本域）、`object` 与键值对编辑器（行为不变）。

---

## 2. 数据契约（后端 → 前端）

后端 `params_model.model_json_schema()` 下发，前端按 `$defs` 解析 `$ref`：

```json
"fallbacks": {
  "type": "array",
  "title": "Fallbacks",
  "description": "备用模型列表…",
  "items": { "$ref": "#/$defs/LLMModelConfig" }
},
"$defs": {
  "LLMModelConfig": {
    "properties": {
      "model":      { "type": "string", "maxLength": 200,  "title": "Model" },
      "server_url": { "type": "string", "maxLength": 2048, "title": "Server Url" },
      "api_key":    { "type": "string", "maxLength": 500,  "title": "Api Key" }
    },
    "required": ["model", "server_url", "api_key"],
    "type": "object"
  }
}
```

约定：

- 元素内部**不再递归数组**（本期不支持嵌套数组；schema 里出现时退化为 JSON 文本域并给出提示）；
- 元素子字段当前支持的类型：`string` / `number` / `integer` / `boolean` / `enum`；
- 元素对象的 `required` 数组决定必填星号与校验；缺省视为全部可选；
- 前端**不修改** schema，只做渲染与本地校验提示，最终合法性由后端 pydantic 强校验兜底。

## 3. 元素结构定义

### 3.1 容器（列表本身）

| 属性 | 值 | 说明 |
| --- | --- | --- |
| 外层容器 class | `action-params-form__array` | 语义锚点，测试/脚本定位用 |
| 布局 | `flex flex-col gap-3` | 元素之间垂直间距 12px |
| 空态 | 见 §6 状态矩阵 | 虚线框 + 文案 + 引导按钮 |
| 底部操作 | 「添加一项」按钮，左对齐 | 追加到数组末尾 |

### 3.2 元素（item）

| 属性 | 值 |
| --- | --- |
| 行容器 class | `action-params-form__array-row` |
| 行容器样式 | `space-y-2 p-3 bg-fill-light rounded border border-border` |
| 序号 | `#{{索引 + 1}}`，左对齐，`font-medium`，颜色 `text-text-regular` |
| 行操作区 | 右对齐：`上移`、`下移`、`删除` |
| 子字段区 | `grid grid-cols-1 lg:grid-cols-2 gap-3` |
| 序号基准 | **1 基**，随排序实时重算 |
| 渲染 key | 行索引 `idx`（受控组件：值通过 `model-value` 显式绑定，不依赖组件内部状态，删除/排序后不会串值） |
| 序列化 | 元素在 `params[key]` 中是纯对象（`Record<string, unknown>`），不含任何 UI 字段 |

### 3.3 子字段（field）

渲染规则由 schema 逐项决定：

| schema 条件 | 控件 | 约束 |
| --- | --- | --- |
| `enum` 非空 | `el-select`（可清空） | 值 ∈ `enum`；清空 → `null` |
| `type: number / integer` | `el-input type="number"` | `min`/`max` 映射为原生属性；非法输入不写入 |
| `type: boolean` | `el-switch`（是/否） | 默认 `false` |
| `type: string` + 敏感名 | `el-input type="password"` + `show-password` | 敏感名匹配 `/(api_?key|secret|token|password)/i` |
| 其它 `string` | `el-input type="text"` | `maxlength = maxLength`，超出不可输入 |

> 动作「输入变量」区（`ActionParamsForm` 顶部）同样按契约类型选控件：```boolean``` 用下拉（是/否）、
> ```number``` 用数字输入、```array```/```object``` 用 JSON 文本域，避免一律单行文本框。

字段标签：

- 文案取 `title || 字段名`；
- 必填时在标签后追加红色 `*`（`text-danger`）；
- 标签使用 `el-text type="info"`（12px，次要色），**不使用 `small` 尺寸属性**；
- 字段级 `description` 作为输入框 `placeholder`（没有则用 `请输入{字段名}`）。

`LLMModelConfig` 的具体定义：

| 字段 | 类型 | 必填 | 最大长度 | 默认 | 校验规则（前端） | 校验规则（后端） |
| --- | --- | --- | --- | --- | --- | --- |
| `model` | string | ✅ | 200 | `""` | 去空白后非空 | `max_length=200` |
| `server_url` | string | ✅ | 2048 | `""` | 去空白后非空；schema 标记 `format: uri` → 必须以 `http://` / `https://` 开头 | `max_length=2048` |
| `api_key` | string | ✅ | 500 | `""` | 去空白后非空 | `max_length=500` |

前端校验只做**行内提示**（红框 + 文案），不阻断其它字段编辑；保存动作由后端 pydantic 强制。

## 4. 层级关系与排序

### 4.1 层级

```
参数卡片（prop.card）
└── 列表容器 action-params-form__array
    ├── 空态 / 行 ×N
    └── 添加按钮
        └── 行 action-params-form__array-row
            ├── 头部（序号 + 上移/下移/删除）
            └── 子字段网格
                └── action-params-form__array-field ×M
```

### 4.2 排序规则

1. **数组顺序即业务优先级**：`index 0` 优先级最高（模型池按顺序回退），因此顺序必须可编辑且语义明确；
2. 新增：**追加到末尾**（不插入到选中项之后），新增后自动滚动到该行（不自动抢焦点，避免打断连续输入）；
3. 上移/下移：**单步移动**；首项禁用「上移」，末项禁用「下移」（`disabled`，不隐藏，避免布局跳动）；
4. 不支持拖拽排序：键盘可达性与触屏体验差，本版本以按钮排序替代；
5. 删除：立即生效，后续元素索引整体前移；**不加二次确认**（可重新点击「添加一项」恢复），但原子项较多时（≥5）删除按钮保持危险色以便误触识别；
6. 不做自动排序/去重：相同 `model` 允许出现多次（可能是不同 key/地址），由用户自行判断。

## 5. 显示逻辑

| 场景 | 显示规则 |
| --- | --- |
| 序号 | `#1`…`#N`，1 基，实时与数组下标一致 |
| 子字段排列 | 宽屏两列：`item.properties` 的键顺序（与 schema 一致）；窄屏单列 |
| 超长值 | `model` / `server_url` 单行显示，`text-ellipsis whitespace-nowrap overflow-hidden`，`title` 属性提供完整值悬停查看；`api_key` 始终掩码 |
| 空字符串 | 显示 placeholder，不显示占位符文字替换（保持可编辑） |
| 空列表 | 显示空态卡片，**不渲染任何行**，但保留「添加一项」 |
| 敏感字段 | 默认 `type=password`，`show-password` 提供「眼睛」临时显形；显形后 5 秒自动回到掩码（可选增强，非强制） |
| 字段顺序变化 | 由 schema 决定，前端不重排（`enum` 字段也按 schema 顺序） |

## 6. 状态矩阵

| 状态 | 触发条件 | 表现 |
| --- | --- | --- |
| **空数据** | `items.length === 0` | 虚线框 + 「暂无条目，点击下方按钮添加」+ 添加按钮；容器高度收缩，不留空白行 |
| **单项** | `length === 1` | 上移/下移均禁用（置灰但保留占位） |
| **多项** | `length ≥ 2` | 上移/下移按位置启用/禁用 |
| **聚焦** | 输入框获得焦点 | 边框使用主题主色（element-plus 默认 focus 态），行容器不变色 |
| **校验错误** | 必填为空 / URL 格式不符 | 输入框边框 `border-danger`，字段下方一行 `text-danger` 文案；错误不阻塞其它行编辑 |
| **超长内容** | 值长度 > 显示宽度 | 单行省略 + `title` 提示；输入框内横向滚动（不换行撑高） |
| **加载中** | 父级 schema 未就绪 | 整个参数区不渲染列表（由父级 loading 控制），不显示空态以免误判 |
| **只读 / 禁用** | 面板为预览态 | 所有输入 `disabled`，按钮隐藏，行容器降低透明度（`opacity-60`）；本期父级无此态，预留 |
| **删除到空** | 删掉最后一项 | 回到「空数据」态，数组写回 `[]`（不是 `undefined`） |

## 7. 交互细节

| 操作 | 行为 | 备注 |
| --- | --- | --- |
| 添加一项 | `[...items, 默认项]`；默认项按子字段类型给初值（`""` / `null` / `false`） | 不复制上一项，避免误存重复 key |
| 删除 | `items.filter((_, i) => i !== index)` | 删除后序号自动重排 |
| 上移 / 下移 | 与相邻项交换 | 首/末项按钮禁用 |
| 键盘 | `Tab` 在字段间移动；`Enter` 不提交表单 | 不拦截浏览器默认行为 |
| 失焦校验 | 字段失焦时计算该字段错误 | 输入过程中不实时报错，避免打断输入 |
| 保存联动 | 列表值随 `formData` 一起提交，无独立保存按钮 | 空数组 = 关闭该能力（如「只用主模型」） |

## 8. 样式规范

| 部位 | Tailwind | 说明 |
| --- | --- | --- |
| 列表容器 | `space-y-2` / `flex flex-col gap-3` | 与上方字段保持 12px 间距 |
| 行容器 | `p-3 bg-fill-light rounded border border-border` | 与 `object` 子卡片一致 |
| 行头部 | `flex items-center justify-between` | 序号左、操作右 |
| 子字段网格 | `grid grid-cols-1 lg:grid-cols-2 gap-3` | 窄屏单列 |
| 字段单元 | `flex flex-col gap-1` | 标签与输入框 4px |
| 主按钮 | `el-button text`（无边框） | 与项目其它「添加」按钮一致 |
| 删除按钮 | `text` + `type="danger"` | 危险色，不填充背景 |
| 错误文案 | `text-xs text-danger mt-1` | 12px |
| 空态 | `text-center py-2 text-text-secondary bg-fill-light rounded border border-dashed border-border` | 虚线框 |

禁止事项（项目规范）：

- 不使用 `<style>` 与内联 `:style`（`el-date-picker` 等历史写法除外，不扩散）；
- element-plus 组件不使用 `size="small"`；
- 颜色只用主题 token（`text-text-regular` / `text-text-secondary` / `text-danger` / `bg-fill-light` / `border-border`），不写死 `#xxx`。

## 9. 响应式适配

| 断点 | 行为 |
| --- | --- |
| `< 640px`（手机） | 子字段单列；行头部操作按钮换行显示（`flex-wrap`）；添加按钮占满宽度 |
| `640 – 1024px`（平板） | 子字段单列；操作按钮同行 |
| `≥ 1024px`（桌面） | 子字段两列（`lg:grid-cols-2`）；行内留白 `p-3` |
| 极窄（< 380px） | 序号与「删除」按钮同行，上移/下移折到第二行 |

对齐要求：同一行内子字段**顶部对齐**（`items-start`），标签在上、控件在下，保证多行错误文案不挤压相邻字段。

## 10. 语义 class 与可访问性

| class | 位置 |
| --- | --- |
| `action-params-form__array` | 列表容器 |
| `action-params-form__array-empty` | 空态 |
| `action-params-form__array-row` | 单行 |
| `action-params-form__array-index` | 序号 |
| `action-params-form__array-up` / `__down` / `__remove` | 行操作按钮 |
| `action-params-form__array-field` | 单个子字段 |
| `action-params-form__array-error` | 字段错误文案 |
| `action-params-form__array-add` | 添加按钮 |

可访问性：按钮均带可读文案（`上移` / `下移` / `删除` / `添加一项`），不只靠图标；删除按钮 `type="danger"` 但不使用 `text-danger` 影响可读性。

## 11. 序列化与后端契约

- 列表值直接写回 `formData[key]`（数组），随 `steps[].params` 提交；
- 空数组 `[]` 与「不传」语义不同：`[]` = 明确关闭（如只用主模型）；不传 = 使用动作默认值；
- 后端 `LLMParams.fallbacks` 为 `list[LLMModelConfig]`，多余字段会被 pydantic 忽略/拒绝（以模型配置为准）；
- 若参数值来自工作流变量（模板串 `{{llm_fallbacks}}`），**不要**写在本列表字段里——LLM 动作用独立参数 `fallbacks_json` 承接，避免列表字段被字符串污染（见 §12）。

## 12. 校验规则汇总

| 层级 | 规则 | 失败表现 |
| --- | --- | --- |
| 元素 | 元素必须是对象 | 前端不渲染该行；后端 422 |
| 字段 | 必填字段去空白后非空 | 行内红框 + `该字段必填` |
| 字段 | `maxLength` 限制（`model` 200 / `server_url` 2048 / `api_key` 500） | 输入框禁止继续输入；超限时失焦提示 `最多 N 个字符` |
| 字段 | schema `format: uri` 的字段必须以 `http://` / `https://` 开头 | `请填写 http(s) 开头的地址` |
| 列表 | 允许为空 | 空数组合法（表示不启用备用模型） |
| 后端 | pydantic 强校验（类型、长度、嵌套模型） | 接口 422，前端展示后端 `detail` |

## 13. 验收用例

| # | Given | When | Then |
| --- | --- | --- | --- |
| 1 | `fallbacks` 无值 | 打开 llm 步骤参数 | 显示空态 + 「添加一项」，不显示任何行 |
| 2 | 空状态 | 点击「添加一项」 | 出现 `#1` 行，三个子字段为空，`api_key` 掩码 |
| 3 | 有 1 行 | 查看行操作 | 「上移」「下移」均禁用，「删除」可用 |
| 4 | 有 2 行 | 点击第 2 行「上移」 | 两行交换，序号重算为 `#1`/`#2`，值跟随行移动 |
| 5 | 填写两行 | 保存后重新打开 | 两行内容完整回显，顺序与保存一致 |
| 6 | `server_url` 填 `abc` | 失焦 | 红框 + 「请填写 http(s) 开头的地址」 |
| 7 | `api_key` 超 500 字 | 继续输入 | 无法输入第 501 个字符 |
| 8 | 填写长 URL | 失去焦点 | 单行省略，悬停可见完整值 |
| 9 | 删除全部行 | — | 回到空态，`params.fallbacks = []` |
| 10 | 宽度 375px | 渲染两行 | 子字段单列，操作按钮换行，无横向滚动 |
