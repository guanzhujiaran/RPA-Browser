# 指纹种子与字段说明（info 图标）

> 关联：`docs/指纹种子设置计划书.md`
> 前端落点：`src/views/rpa-browser/FingerprintCreateEdit.vue`（创建 / 编辑通用）

## 1. 指纹种子字段

| 项 | 值 |
|---|---|
| 位置 | 「基础配置」卡片，紧跟「指纹名称」 |
| 控件 | `el-input-number`（默认尺寸，不用 `small`） |
| 范围 | `-2147483648 ~ 2147483647`（后端 `Int32`） |
| 默认 | 空（`null`）。**留空 = 创建时由后端随机生成** |
| 写入 | `upsert_fingerprint` 的 `fingerprint_int` |
| 回显 | `read_fingerprint` 的 `fingerprint`（注意：生成类型里写作 `'--fingerprint'`，
  与实际响应字段名不一致，读取按 `fingerprint` 取） |

行为：

- 编辑态回显库里已有种子；修改后保存即换种子（下次启动生效）；
- 种子必须全局唯一（DB 唯一约束）。重复时后端返回业务错误，前端直接展示 `msg`；
- 种子为 `0` 是合法值（不等于「留空」）；
- 「随机生成」会连种子一起换新（回填响应里的 `fingerprint`）；
- 只读展示：指纹详情页与列表的详情弹窗都增加「指纹种子」一项（等宽字体），
  便于判断两个浏览器是否共用同一套派生指纹。

## 2. 说明文案 → 字段标签 info 图标

要求：表单里所有的说明文字（原来表单底部的灰色小字）统一改为**标签右侧 info 图标**，
悬浮或点击展示 `el-tooltip`，不再以整段灰字平铺占版面。

| 字段 | tooltip 文案 |
|---|---|
| 指纹种子 | 决定 canvas / audio / ClientRects / 字体等派生值，同一个种子等于同一台虚拟设备。留空创建时随机；同一种子会让两个浏览器互相可关联，所以必须全局唯一。 |
| 代理服务器 | 建议一个浏览器一个独立代理：同一出口 IP 被多个账号共用时，站点会按 IP 维度风控（验证码、登录态互踢、限流直至封禁），指纹再逼真也补救不了。留空则使用服务端默认代理。 |
| 代理绕过 | 命中的域名/IP 不走代理，逗号分隔；只支持域名或 IP，不能带 http 前缀。未配置代理时不生效。（未配代理时代替为「该浏览器未配置代理，绕过列表不生效」） |
| 真实版本 | 决定实际启动哪个 chromium 二进制，只能从服务端清单里选；清单外的版本后端会拒绝。 |
| 模拟版本 | 页面读到的报告版本，默认等于真实版本；只能在同一主版本内改 patch（跨主版本与内核特性集 / TLS 对不上，后端会拒绝）。 |
| GPU 厂商 / GPU 渲染器 | 仅对 Chrome 143 及以下内核生效；≥144 内核已移除该开关，实际 GPU 由指纹种子决定。（当前版本不生效时图标转为琥珀色） |

图标规范（`.codebuddy/rules/icons.mdc`）：

- 用 assets 下已归一化的 SVG（`@/assets/svgs/space/help.svg?component`），
  尺寸/颜色由外部 class（`w-3.5 h-3.5 text-text-placeholder`）控制；
- 不用 Element Plus 内置图标充当业务图标；
- 图标与标签同行、`cursor-help`，悬浮显示，不做成整段可点击文字。

## 3. 验收

- [ ] 新建时填种子 → 保存后回读一致；
- [ ] 留空创建 → 自动随机且回显；
- [ ] 重复种子 → 展示后端 msg，不是 500；
- [ ] 每个字段标签右侧有 info 图标，悬浮出说明；
- [ ] GPU 在 ≥144 时图标变琥珀色，tooltip 里说明「不生效，由种子决定」。
