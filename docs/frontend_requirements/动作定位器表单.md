# 动作定位器（locator）参数表单需求

## 背景

元素级动作（`click` / `input` / `hover` / `get_text` / `wait` / `element_state` /
`select_option` / `press` / `scroll` / `screenshot` / `wait_for_response`）的参数
已从裸 `selector: str` 改为定位器对象 `locator`：

```json
{
  "locator": {
    "strategy": "css",
    "value": ".side-toolbar__action.like",
    "pick": "first",
    "state": "attached",
    "timeout_ms": 8000,
    "within": null,
    "frame": null,
    "has_text": null,
    "exact": false
  },
  "fallbacks": [
    { "value": ".dyn-card-opus" },
    { "value": ".bili-dyn-card-video" }
  ],
  "missing": "fail"
}
```

后端参数 schema（`parameters_schema[].json_schema`）已经输出上述结构：
`locator` 是**一层嵌套对象**（字段全为标量/枚举），`fallbacks` 是**对象数组**。

## 现状（无需改动即可用）

`ActionParamsForm.vue` 现有能力已能渲染：

- 嵌套对象分支（`prop.type === 'object' && prop.properties`）→ `locator` 的
  `strategy` / `pick` / `state` 走 `el-select` 下拉，`value` / `within` / `frame`
  走文本输入，`exact` 走开关，`timeout_ms` 走数字输入；
- 对象数组分支 + `ObjectArrayEditor.vue` → `fallbacks` 每条候选可增删、可编辑字段；
- 空壳兼容：表单预填的 `{"value": ""}` 会被后端归一成「没有定位器」
  （`press` 发给当前焦点、`scroll` 滚整页等分支不受影响）。

## 待优化（本期需求）

1. **字段顺序与折叠**：`locator` 展开后 9 个字段全部平铺，把最常填的
   `value` 挤到中间。要求渲染顺序为
   `strategy → value → pick/nth → has_text → state → timeout_ms → within → frame → exact`，
   并把 `within` / `frame` / `exact` 收进「高级」折叠区（默认收起）。
2. **`pick=nth` 联动**：仅当 `pick === "nth"` 时显示 `nth` 输入，其余情况隐藏，
   避免用户填了 `nth` 却没选 `pick` 而不生效。
3. **字段标签用业务语言**，不要直接暴露 `has_text` / `within` / `frame`：
   - `strategy` → 定位方式
   - `value` → 定位值（按 strategy 给出占位提示：
     css=`.class`、text=`可见文本`、role=`button`、xpath=`//div[@id]`）
   - `pick` → 命中多个时取哪个
   - `has_text` → 额外要求包含文本
   - `state` → 等到元素达到状态
   - `timeout_ms` → 定位超时（毫秒，留空=用动作超时）
   - `within` → 限定在父元素内（CSS）
   - `frame` → 在 iframe 内（CSS）
4. **候选链语义提示**：`fallbacks` 上方加一行说明「按顺序尝试，前面的 0 命中才用下一个」，
   并支持上下移动排序（优先级由顺序决定）。
5. **`missing` 下拉**（`fail` / `ignore`）只在有 `locator` 的动作上展示；
   `ignore` 时给一句提示「元素不存在按跳过处理，不判失败」。
6. **迁移完成后的清理**：`locator` 为 `null` 时不要立刻生成空壳对象，
   改为「点击『添加定位器』按钮后才创建」，避免所有可选定位器的动作
   （`press` / `input` / `scroll`）默认多出一个空定位器分组。

## 约束

- 遵守项目主题规范：只用 Tailwind 语义类，禁止 `<style>` 与内联 `:style`；
- 不改 `hey-api` 生成代码；`parameters_schema` 的类型来自 `types.gen.ts`，如需扩展由后端提供；
- 不引入新的字典/自由 JSON 输入框来编辑 `locator`。
