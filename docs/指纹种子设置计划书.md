# 指纹种子（fingerprint）设置计划书（v1）

> 状态：已确认（2026-11-26）。关联：`docs/frontend_requirements/指纹种子与字段说明.md`

## 1. 需求

1. 指纹创建/编辑表单除「指纹名称」外，还要能**查看并设置指纹种子**；
2. 表单里说明种子的作用（以及其它字段的说明）；
3. 说明文字不再以表单底部灰字平铺，统一收敛到**字段标签右侧的 info 图标**，
   悬浮 / 点击展示 tooltip。

## 2. 种子是什么

`--fingerprint=<32 位整数>` 是 fingerprint-chromium 的**伪装开关 + 种子**：

- 传了它，大部分伪装才生效（canvas、audio、ClientRects、字体、内存/核数等）；
- 派生值由种子决定 → **同一个种子 = 同一台「虚拟设备」**，跨会话稳定；
- 换一个种子 = 换一整套派生指纹（canvas/audio 等全变）。

因此：`userbrowserinfo.fingerprint` 是浏览器身份的根，重建会话时不能变；
「复制指纹」会连种子一起复制，等于两台可关联的设备，要区分必须换种子。

## 3. 现状与问题

| 项 | 现状 | 问题 |
|---|---|---|
| 存储 | `userbrowserinfo.fingerprint`，`NOT NULL` + `UniqueConstraint('fingerprint')` | 全局唯一，重复种子会写库失败 |
| 入参 | `BrowserFingerprintEditableParams.fingerprint_int` | 创建时被丢弃（见下） |
| 出参 | 字段名 `fingerprint`（read/list 用 `response_model_by_alias=False`） | 与入参名 `fingerprint_int` 不同名 |
| 生成 | `gen_from_browserforge_fingerprint` 写死 `random.randint(...)` | **创建时传的种子无效**；upsert 创建分支又用 `exclude={"fingerprint_int"}` 过滤掉 |
| 下发 | `fp_2_args_list` 用 `if not v: continue` 过滤 | `seed=0` 被当空值丢掉 → **内核伪装全关** |

## 4. 后端改动

1. **尊重入参种子**：`gen_from_browserforge_fingerprint` 改为
   `params.fingerprint_int if not None else random.randint(...)`。
2. **唯一性校验**：upsert / update 写库前查 `fingerprint` 是否已被占用（更新时排除自己），
   命中抛 `FingerprintSeedAlreadyExistsException`（复用 `ResponseCode.NAME_ALREADY_EXISTS`，
   HTTP 200 + 业务码，前端能直接展示 msg）。
3. **修 `fp_2_args_list` 判空**：改为 `is None` / 空串判断，保证 `seed=0` 也能下发。
4. 出参字段名保持 `fingerprint` 不变（SDK 里是 `'--fingerprint'`，前端按运行时字段名读，见 §5）。

## 5. 前端改动

- 基础配置卡片、指纹名称下方新增「指纹种子」`el-input-number`：
  - 范围 `-2147483648 ~ 2147483647`（Int32）；
  - **留空 = 创建时随机生成**；编辑时回显库里已有的种子；
  - 提交走 `fingerprint_int`，读取走 `data.fingerprint`（生成类型里写作 `'--fingerprint'`，
    与实际响应字段名不一致，读取处按字段名取，必要时 `as any`）。
- 所有字段说明改成标签右侧 info 图标 + `el-tooltip`；
  图标用 assets 下已归一化的 SVG（`src/assets/svgs/space/help.svg?component`），
  不用 Element Plus 内置图标（见 `.codebuddy/rules/icons.mdc`）。
- 动态状态（GPU 在 ≥144 不生效、代理绕过在未配代理时不生效）写进 tooltip 文案，
  并用图标颜色（琥珀）提示，不再额外占版面。

## 6. 验收

- [ ] 新建指纹时填种子 → `read_fingerprint` 返回同一值，`--fingerprint=<该值>` 出现在命令行；
- [ ] 种子留空 → 自动随机，且能读回；
- [ ] 填一个已被占用的种子 → 返回业务错误并展示提示（不是 500）；
- [ ] 编辑已有指纹时种子回显、可修改；
- [ ] 每个字段标签右侧有 info 图标，悬浮出现说明。
